# CSV取り込みフォーマット仕様

データをCSVファイルからインポートする際のフォーマットについて説明します。

## 棒グラフ用

ヘッダー行（1行目）にはカラム名を記載し、2行目以降にデータを入力します。

### フォーマット

```csv
ラベル,値
項目1,100
項目2,200
項目3,150
```

### 例

```csv
ラベル,値
フリーザ,530000
ギニュー,120000
リクーム,71000
バータ,68000
ジース,64000
```

### 注意事項

- 1列目: ラベル（文字列）
- 2列目: 数値
- ヘッダー行は必須です（内容は任意）
- 数値に単位やカンマは含めないでください

---

## 折れ線グラフ用

横持ち形式で、1行目にX軸ラベル、2行目以降に各系列のデータを入力します。

### フォーマット

```csv
系列名,ラベル1,ラベル2,ラベル3,...
系列A,100,120,140,...
系列B,80,90,100,...
```

### 例

```csv
系列名,1月,2月,3月,4月,5月,6月
売上,100,120,115,140,160,180
利益,30,35,32,45,55,70
```

### 注意事項

- 1行目1列目: 任意（「系列名」など）
- 1行目2列目以降: X軸のラベル
- 2行目以降1列目: 系列名
- 2行目以降2列目以降: 数値データ
- 複数系列を追加可能

---

## 共通仕様

### 文字コード

- UTF-8を推奨

### エスケープ

- カンマを含む値はダブルクォートで囲んでください
  - 例: `"東京,大阪",100`
- ダブルクォート自体を含める場合は2つ重ねてください
  - 例: `"He said ""Hello""",100`

### エラーについて

| エラー | 原因 |
|-------|------|
| CSVファイルが空です | ファイルにデータがありません |
| データ行がありません | ヘッダー行のみでデータがありません |
| 「{値}」は数値ではありません | 数値欄に数値以外が入力されています |
| 列数が不足しています | 必要な列が足りません |
