# Data Visualize Designer

[goandoさんのデータ視覚化のデザイン](https://note.com/goando/m/me00d3667f5ce)を参考に、「正しいグラフ」を作成できるWebアプリケーションです。

## 機能

### グラフ種類
- **横棒グラフ**: 複数項目の比較に最適
- **縦棒グラフ**: 時系列比較に適した形式
- **折れ線グラフ**: 複数系列対応、トレンドの可視化に最適

### グラフ設定

#### カラーテーマ（6種類 + カスタム）
- Blue / Green / Purple / Gray / Orange
- カスタムカラー: 任意の色を指定して自動でグラデーション生成

#### 配色モード
- **濃淡**: データ数に応じて濃淡をつけた配色
- **同色**: すべてのバーを同じ色で統一
- **強調**: 選択したデータのみ濃色、その他は灰色

#### 画像比率
- 1:1（正方形）
- 4:3（標準）
- 16:9（ワイドスクリーン）

#### フォント
- システムフォント
- Noto Sans JP

#### 折れ線グラフ専用設定
- **線のスタイル**: 直線 / 曲線
- **ラベル表示**: 終端（インライン）/ 凡例

### データ入力

#### 手動入力
- グラフタイトル（伝えたいメッセージ）
- 項目の追加・削除
- 強調モード時は強調する項目を選択可能
- 折れ線グラフは複数系列に対応

#### CSV取り込み
- **棒グラフ**: `ラベル,値` 形式
- **折れ線グラフ**: 横持ち形式（系列名とX軸ラベル）
- エラーハンドリング付き

### エクスポート
- **PNG形式**: 高解像度（3倍）で出力
- **SVG形式**: 透過背景オプション付き

### デザイン原則への対応
- 伝えたいメッセージをタイトルとして明確に表示
- Y軸は必ずゼロから開始
- 目盛りは最小限に（自然な間隔で自動計算）
- 色覚異常への配慮（明度差で区別可能）

### その他
- レスポンシブ対応
- アニメーション付きグラフ描画
- 数値の自動フォーマット（K/M単位、3桁区切り）

## 技術スタック

- [Next.js](https://nextjs.org/) 14
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [D3.js](https://d3js.org/)
- [html-to-image](https://github.com/bubkoo/html-to-image)

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

[http://localhost:3000](http://localhost:3000) をブラウザで開いてください。
